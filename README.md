## What I'm building: ReelRent
ReelRent is a video-first apartment rental app for New York City. Renters set what matters (neighborhood, commute, budget, space, timing, amenities), get ranked daily picks as swipeable cards and apartment Reels, save homes, message the listing professional about a specific unit, and book viewings. Roommates and partners can search together. NYC agents, brokers, and property managers publish their own profiles, listings, and Reels.
